# Historial de versiones

Este documento registra cambios relevantes de la versión web pública de **Torre Multiversal**. Las instrucciones de publicación están en [PUBLICACION.md](PUBLICACION.md).

## v0.15 · 7 de noviembre de 2026

**Origen:** archivos de distribución `torre-multiversal-web (2).zip` y fuentes `torre-multiversal-fuente (1).zip`.

### Novedades integradas

- Primera fase de doma por comportamiento y confianza para cinco especies: limo, lanudo, jabalí de ámbar, zorro ilusionista y liebre trueno.
- Criaturas compañeras con seguimiento, participación en combate y progresión del vínculo.
- Integración de la doma y las compañeras con el protocolo de multijugador y el guardado.
- Ajustes de interfaz y sistemas procedentes de la versión web entregada.

### Publicación

- Actualizados `game.js` e `index.html` en `main`.
- Conservados los recursos gráficos, manifiesto de instalación, README y configuración de GitHub Pages.
- Se renovó la referencia de versión del script: `game.js?v=mw735hq0`.

### Comprobaciones

- Sintaxis de `game.js`: correcta.
- 46 pruebas unitarias de doma, red y guardado: aprobadas.
- 11 pruebas unitarias de personaje: aprobadas en ejecución independiente.
- Prueba de la versión publicada en navegador y de una sala multijugador real: pendiente de comprobar para esta actualización.

> **Nota:** El ZIP de fuentes fue entregado para revisión, pero no se incorporó como árbol de módulos a este repositorio. Los cambios publicados corresponden a los archivos web ya compilados.
